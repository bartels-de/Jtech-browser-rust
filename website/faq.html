Questions and answers

Is JTech Browser a replacement for Chrome or Edge?▾

Not yet. It is a focused browser for people who want vertical tabs, built-in blocking and a customizable UI. Some advanced features like full extension stores, profiles or mobile sync are still missing.

Why does the installer trigger SmartScreen?▾

The installer is not yet signed with an expensive Windows publisher certificate. The file is safe, the source code is public and the browser itself verifies update signatures separately.

Does it work on macOS or Linux?▾

Currently only Windows 10 and 11 are supported, because WebView2 is the rendering engine and the windowing code is Windows-specific right now.

Where is my data stored?▾

Bookmarks, history, settings and permissions are stored in a local SQLite file inside your AppData folder. No account or cloud is required.

Can I import my bookmarks from another browser?▾

Yes. The importer can read bookmarks and history from Chrome, Edge, Brave and Firefox profiles and lets you merge them into JTech.
