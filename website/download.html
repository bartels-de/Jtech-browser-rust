System requirements

  • Windows 10 or 11, 64-bit (x64)
  • Microsoft Edge WebView2 Runtime. Windows 11 already includes it; on Windows 10 it is usually present and otherwise set up by the installer.
A warning on first start is expected The installer is not yet signed with a Windows publisher certificate, so Microsoft SmartScreen may warn you. Choose "More info" and then "Run anyway". This is separate from the update signature the browser checks before installing its own updates.
Early software JTech Browser is at version 0.x. Expect rough edges and changes between releases. If something breaks, please open an issue.
