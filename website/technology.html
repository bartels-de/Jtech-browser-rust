What it is built with

JTech Browser combines a fast native shell with a modern web UI and a Rust backend.

⚡

Tauri 2 + Rust

The shell is written in Rust and uses Tauri 2 to create the window and host the UI webview. That keeps memory low, startup fast and the native layer small.

🌐

Microsoft Edge WebView2

Websites render with the same engine as Edge, so compatibility is high. Each web tab is a separate WebView2 instance, managed from Rust.

⚛️

React + TypeScript

The interface, settings, start page and all internal pages are built with React 19 and TypeScript, compiled by Vite.

🛡️

adblock-rust

Network requests are checked in Rust with Brave's open-source engine against EasyList, EasyPrivacy and optional extra lists.

🗄️

SQLite

Bookmarks, history, settings, permissions and block statistics live in a local SQLite database. Nothing leaves your PC unless you open a website.

🔒

Signed updates

The built-in updater fetches releases from GitHub and verifies the signature before installing. You can disable automatic checks.

How the pieces fit together

1

One UI webview

Spans the whole window and draws the sidebar, toolbar and internal pages.

2

One content webview per tab

Positioned over the content area and resized from Rust as the window or sidebar changes.

3

Rust in the middle

Creates webviews, routes IPC commands, filters requests, persists data and handles WebView2 events.

4

React mirrors Rust state

Through Tauri events, the UI updates without polling.

Why this stack?

Rust gives memory safety and performance for the native layer. Tauri 2 provides a small, secure bridge between web UI and native code. WebView2 means websites work exactly as in Edge without shipping a separate rendering engine. React lets us build a rich, responsive interface quickly, while SQLite keeps all your data local and queryable.

The result is a browser that starts fast, uses fewer resources than Electron-based alternatives, and still supports modern web standards and a customizable interface.
